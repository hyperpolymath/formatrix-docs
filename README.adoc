== License & Philosophy

This project must declare **MPL-2.0-or-later** for platform/tooling compatibility.

Philosophy: **Palimpsest**. The MPL-2.0 (PMPL) text is provided in `license/MPL-2.0.txt`, and the canonical source is the palimpsest-license repository.

Formatrix Docs is the tabbed viewer and editor of one logical document
(TXT/MD/ADOC/DJOT/ORG/RST/TYP). Gossamer GUI + Ada TUI. Graph visualization,
OCR, TTS/STT, and Nickel pipelines are in-tree capabilities of *this* project.
Multi-format conversion is the separate
https://github.com/hyperpolymath/docmatrix[DocMatrix] project; GUI, TUI, graph,
and editor claims must not be attributed to DocMatrix.

== Features

* *Format Tabs* - View and edit the same document in multiple markup formats
* *Suite boundary* - Viewing/editing stays here; conversion is DocMatrix; PDF placement is Blocky Writer
* *Unified AST* - Shared representation behind the format tabs
* *GUI* - Gossamer with AffineScript frontend
* *TUI* - Ada with AdaCurses for terminal usage
* *Graph Visualization* - ArangoDB for document relationships
* *Accessibility* - OCR, TTS, STT support
* *Pipelines* - Nickel-based import/export transformations

== Precision document suite

Formatrix Docs owns exactly one thing: **tabbed viewing and editing of one
logical document**. Synchronised editing across tabs is the intended
progression.

It deliberately does *not* do any of the following, and each has an owner:

* Multi-format conversion and precision coordination — https://github.com/hyperpolymath/docmatrix[DocMatrix]
* Fixed-layout PDF and application-form placement — https://github.com/hyperpolymath/blocky-writer[Blocky Writer]

Viewer/editor behaviours such as cursor mapping, synchronised tabs, and
undo/redo are proved here. Conversion round-trips are proved in DocMatrix.
Page-coordinate geometry is proved in Blocky Writer. Those proof obligations
do not transfer.

The versioned composition contract is
https://github.com/hyperpolymath/docmatrix/issues/71[docmatrix#71]. The
long-form boundary statement — including the `detect_blocks` seam Blocky Writer
emits, recorded so neither side invents it twice — is
link:docs/ecosystem/ECOSYSTEM.adoc[docs/ecosystem/ECOSYSTEM.adoc].

== Quick Start

[source,bash]
----
# Check dependencies
just deps

# Build all components
just build

# Run GUI
just run-gui

# Run TUI
just run-tui
----

== Architecture

[source]
----
crates/
├── formatrix-core/     # AST, parsers, renderers
├── formatrix-gui/      # Gossamer commands
├── formatrix-db/       # ArangoDB client
└── formatrix-pipeline/ # Nickel executor

tui/src/                # Ada TUI source
ui/src/                 # AffineScript components
pipelines/              # Nickel pipeline definitions
container/              # Wolfi container configs
----

== Development

=== Prerequisites

* Rust (stable)
* Deno
* GNAT + gprbuild (for TUI)
* Gossamer + WebKit2GTK (for GUI)

=== Build Commands

[source,bash]
----
just build           # Build all
just build-core      # Build Rust core only
just build-tui       # Build Ada TUI only
just build-ui        # Build AffineScript UI only
just test            # Run all tests
just fmt             # Format all code
just lint            # Lint all code
----

=== Containers

[source,bash]
----
just container-build           # Build Wolfi image
just compose-up                # Start with ArangoDB
just container-run-tui         # Run TUI in container
----
